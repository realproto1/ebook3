1. 프로젝트 개요

무엇을 만드는가?

탱고북은 부모나 교사가 AI의 도움을 받아 어린이를 위한 맞춤형 동화책을 생성하고, 생성된 동화책을 어린이가 읽고 학습할 수 있는 통합 플랫폼입니다.

저작 도구

AI로 동화책을 자동 생성하고 편집하는 도구

동화책 뷰어

생성된 동화책을 탐색하고 선택하는 도서관

리더 앱

어린이가 동화책을 읽고 학습하는 모바일 뷰어

왜 만드는가?

  • 교육 효과: 어린이의 연령과 수준에 맞는 맞춤형 콘텐츠 제공
  • 접근성: 누구나 쉽게 양질의 동화책을 생성하고 활용
  • 비용 절감: 전문 일러스트레이터 없이도 고품질 삽화 생성
  • 학습 지원: TTS, 퀴즈, 어휘 학습 등 다양한 교육 기능 통합

3. 핵심 기능 분류

기능 맵 (Feature Map)

저작 기능

(Author Tool)
  • 동화책 생성: AI 자동 생성
  • 캐릭터 생성: AI 이미지 생성
  • 삽화 생성: 페이지별 이미지
  • 표지 생성: 커버 이미지
  • TTS 생성: 음성 자동 생성
  • 어휘 관리: 핵심 단어 정의
  • 퀴즈 생성: 이해도 테스트
  • 편집 기능: 텍스트/이미지 수정

뷰어 기능

(Viewer)
  • 도서 목록: 전체 동화책 탐색
  • 필터링: 연령별/스타일별
  • 정렬: 최신순/제목순
  • 상세 보기: 동화책 정보
  • 공개/비공개: 권한 관리

리더 기능

(Reader)
  • 페이지 전환: 좌우 스와이프
  • TTS 재생: 음성 듣기
  • 자동 재생: 연속 재생
  • 진행률 표시: 현재 페이지
  • 풀스크린: 몰입 모드
  • 게임: 5가지 학습 게임

상세 기능 명세

F1. 동화책 자동 생성 (AI Generation)

입력 (Input)
  • • 제목 (Title)
  • • 타겟 연령 (4-5세, 5-7세, 7-8세)
  • • 페이지 수 (10, 15, 20페이지)
  • • 아트 스타일 (수채화, 애니메이션 등)
  • • 캐릭터 수 (1~5명)
출력 (Output)
  • • 스토리 구조 (기승전결)
  • • 페이지별 텍스트
  • • 캐릭터 정보 (이름, 특징)
  • • 핵심 어휘 목록
  • • 퀴즈 문제 (선택형)
처리 과정
1. 프롬프트 생성 2. Gemini API 호출 3. JSON 파싱 4. DB 저장

F2. 이미지 생성 (Image Generation)

캐릭터 이미지
  • • AI 프롬프트 기반
  • • 캐릭터별 일관성
  • • 다양한 표정/포즈
페이지 삽화
  • • 텍스트 기반 생성
  • • 캐릭터 참조 이미지
  • • 아트 스타일 일관성
표지 이미지
  • • 전체 스토리 요약
  • • 메인 캐릭터 포함
  • • 히스토리 관리

F3. TTS (Text-to-Speech) 음성 생성

지원 모델
  • • Gemini TTS (기본)
  • • Google Cloud TTS
  • • ElevenLabs (프리미엄)
기능
  • • 페이지별 개별 생성
  • • 음성 스타일 선택
  • • 일괄 생성 (병렬)

왜 클린 아키텍처인가?
  • ✅ 관심사의 분리: UI, 비즈니스 로직, 데이터 접근 완전 분리

의존성 규칙 (Dependency Rule)

✅ 허용되는 의존성 방향
• Presentation → Application → Domain ← Infrastructure
• 외부 레이어는 내부 레이어를 의존할 수 있음
• 예: Use Case는 Domain Entity를 사용 가능
❌ 금지되는 의존성 방향
• Domain → Infrastructure (절대 안 됨!)
• Domain → Application (절대 안 됨!)
• 예: Domain Entity에서 R2Client를 직접 호출하면 안 됨
🔄 의존성 역전 (Dependency Inversion)
• Domain이 Repository 인터페이스를 정의
• Infrastructure가 Repository 구현체를 제공
• Application은 인터페이스만 의존 (구현체 모름)

7. 프롬프트 규약 & AI 설정

탱고북의 핵심 기능: AI 이미지 생성 프롬프트 규약

일관된 품질의 동화책 이미지를 생성하기 위한 체계적인 프롬프트 빌딩 규칙입니다.

7.1 표지 이미지 프롬프트 규약

함수: buildCoverPrompt(storybook)

동화책 표지 이미지 생성을 위한 프롬프트를 자동으로 생성합니다.

function buildCoverPrompt(storybook) { const title = storybook.title || '동화책'; const theme = storybook.theme || ''; const artStyle = storybook.artStyle || 'Disney animation style'; const characters = storybook.characters.map(c => c.name).join(', '); return `Create a beautiful, professional book cover illustration... **Book Title:** ${title} **Theme:** ${theme} **Art Style:** ${artStyle} **Main Characters:** ${characters} **Cover Requirements:** - Eye-catching, vibrant illustration - Show the main characters in an engaging scene - Magical atmosphere suitable for children ages 4-8 - Professional book cover quality **DO NOT include:** - Any text, title, or letters on the cover - Book spine or binding elements - Just pure illustration`; }
입력 데이터
  • • 동화책 제목 (title)
  • • 주제/테마 (theme)
  • • 그림체 스타일 (artStyle)
  • • 주요 캐릭터 목록 (characters)
출력 제약사항
  • • 텍스트/글자 표시 금지
  • • 책 등받이 요소 제거
  • • 순수 일러스트레이션만
  • • 4-8세 어린이 적합성

7.2 캐릭터 레퍼런스 시트 프롬프트 규약

함수: buildCharacterPrompt(description, artStyle, settings, isRegeneration)

캐릭터 일관성을 위한 레퍼런스 시트 생성 프롬프트입니다.

레퍼런스 시트 구성
  • 1. 정면 전신 뷰
  • 2. 3/4 뷰 & 측면
  • 3. 3가지 표정
  • 4. 의상/색상 디테일
재생성 모드
  • • 기존 레퍼런스 이미지 분석
  • • 핵심 디자인 요소 유지
  • • 명시된 변경사항만 적용
  • • 색상 팔레트 일관성
제약사항
  • • NO TEXT (텍스트 금지)
  • • 흰색 배경 + 그리드
  • • 4-8세 적합 디자인
  • • 고품질 일러스트
재생성 모드 우선순위
  1. 1️⃣ Reference Image - 기본 디자인
  2. 2️⃣ Updated Description - 수정사항만
  3. 3️⃣ Art Style - 레퍼런스에 이미 확립됨

7.3 페이지 삽화 이미지 프롬프트 규약

함수: buildIllustrationPrompt(page, artStyle, characterReferences, settings, editNote)

스토리 페이지별 삽화 생성을 위한 가장 복잡하고 정교한 프롬프트입니다.

🎯 핵심 기능
  • 자동 캐릭터 감지: 페이지 텍스트 분석해 등장 캐릭터만 필터링
  • 스토리 컨텍스트: 최근 3페이지 내용 포함 (타임아웃 방지)
  • 이전 페이지 참조: 바로 전 페이지 이미지로 일관성 유지
  • 재생성 모드: editNote 있으면 스토리 컨텍스트 생략
📋 프롬프트 구성요소
  • • Scene Description: 장면 묘사
  • • Scene Structure: 캐릭터/배경/분위기
  • • Character References: 필터링된 캐릭터 레퍼런스
  • • Art Style: 일관된 그림체
  • • Composition: 수평 레이아웃
  • • Lighting & Atmosphere: 조명/분위기
  • • Color Palette: 4-8세 적합 색상
재생성 모드 동작 방식

STEP 1 - 레퍼런스 이미지 분석:

  • • 현재 삽화 이미지 (현재 상태)
  • • 캐릭터 레퍼런스 시트 (캐릭터 일관성)
  • • 선택된 레퍼런스 페이지들 (추가 컨텍스트)

STEP 2 - 수정 요청 읽기:

  • • editNote가 있으면: 사용자 요청대로 생성
  • • editNote가 없으면: 약간 변형된 버전 생성

7.4 이미지 생성 모델 선택 옵션

탱고북은 다양한 AI 이미지 생성 모델을 지원하며, 이미지 타입별로 최적의 모델을 선택할 수 있습니다.

이미지 타입별 모델

1. 표지 이미지 (coverModel)

동화책 표지 생성용 - 고품질, 매력적인 표지

2. 캐릭터 레퍼런스 (characterModel)

캐릭터 일관성 유지용 - 정확한 레퍼런스 시트

3. 페이지 삽화 (illustrationModel)

스토리 페이지용 - 세밀한 장면 표현

4. 주요 사물 (keyObjectModel)

스토리 핵심 사물 - 단순하고 명확한 표현

5. 어휘 카드 (vocabularyModel)

어휘 학습용 - 직관적이고 교육적

이미지 설정 (imageSettings)

let imageSettings = { aspectRatio: '16:9', enforceNoText: true, enforceCharacterConsistency: true, additionalPrompt: '', imageQuality: 'high', characterModel: 'gemini-3-pro', keyObjectModel: 'gemini-3-pro', illustrationModel: 'gemini-3-pro', vocabularyModel: 'gemini-3-pro', coverModel: 'gemini-3-pro' };

저장 위치: localStorage.getItem('imageSettings')

지원 모델: gemini-3-pro-image-preview, gemini-2-flash-image-generation 등

TTS (음성 합성) 설정

ttsModel: 'gemini-tts-1', ttsVoiceConfig: { speakingRate: 0.9, pitch: 0, volumeGainDb: 0 }

TTS 생성 시점:

  • • 페이지별 텍스트 음성 생성
  • • 자동 재생 기능 지원
  • • R2에 오디오 파일 저장
  • • 리더 앱에서 재생
