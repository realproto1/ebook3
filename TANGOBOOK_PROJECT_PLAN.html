1. 프로젝트 개요

무엇을 만드는가?

탱고북은 부모나 교사가 AI의 도움을 받아 어린이를 위한 맞춤형 동화책을 생성하고, 생성된 동화책을 어린이가 읽고 학습할 수 있는 통합 플랫폼입니다.

저작 도구

AI로 동화책을 자동 생성하고 편집하는 도구

동화책 뷰어

생성된 동화책을 탐색하고 선택하는 도서관

리더 앱

어린이가 동화책을 읽고 학습하는 모바일 뷰어

왜 만드는가?

  • 교육 효과: 어린이의 연령과 수준에 맞는 맞춤형 콘텐츠 제공
  • 접근성: 누구나 쉽게 양질의 동화책을 생성하고 활용
  • 비용 절감: 전문 일러스트레이터 없이도 고품질 삽화 생성
  • 학습 지원: TTS, 퀴즈, 어휘 학습 등 다양한 교육 기능 통합

3. 핵심 기능 분류

기능 맵 (Feature Map)

저작 기능

(Author Tool)
  • 동화책 생성: AI 자동 생성
  • 캐릭터 생성: AI 이미지 생성
  • 삽화 생성: 페이지별 이미지
  • 표지 생성: 커버 이미지
  • TTS 생성: 음성 자동 생성
  • 어휘 관리: 핵심 단어 정의
  • 퀴즈 생성: 이해도 테스트
  • 편집 기능: 텍스트/이미지 수정

뷰어 기능

(Viewer)
  • 도서 목록: 전체 동화책 탐색
  • 필터링: 연령별/스타일별
  • 정렬: 최신순/제목순
  • 상세 보기: 동화책 정보
  • 공개/비공개: 권한 관리

리더 기능

(Reader)
  • 페이지 전환: 좌우 스와이프
  • TTS 재생: 음성 듣기
  • 자동 재생: 연속 재생
  • 진행률 표시: 현재 페이지
  • 풀스크린: 몰입 모드
  • 게임: 5가지 학습 게임

상세 기능 명세

F1. 동화책 자동 생성 (AI Generation)

입력 (Input)
  • • 제목 (Title)
  • • 타겟 연령 (4-5세, 5-7세, 7-8세)
  • • 페이지 수 (10, 15, 20페이지)
  • • 아트 스타일 (수채화, 애니메이션 등)
  • • 캐릭터 수 (1~5명)
출력 (Output)
  • • 스토리 구조 (기승전결)
  • • 페이지별 텍스트
  • • 캐릭터 정보 (이름, 특징)
  • • 핵심 어휘 목록
  • • 퀴즈 문제 (선택형)
처리 과정
1. 프롬프트 생성 2. Gemini API 호출 3. JSON 파싱 4. DB 저장

F2. 이미지 생성 (Image Generation)

캐릭터 이미지
  • • AI 프롬프트 기반
  • • 캐릭터별 일관성
  • • 다양한 표정/포즈
페이지 삽화
  • • 텍스트 기반 생성
  • • 캐릭터 참조 이미지
  • • 아트 스타일 일관성
표지 이미지
  • • 전체 스토리 요약
  • • 메인 캐릭터 포함
  • • 히스토리 관리

F3. TTS (Text-to-Speech) 음성 생성

지원 모델
  • • Gemini TTS (기본)
  • • Google Cloud TTS
  • • ElevenLabs (프리미엄)
기능
  • • 페이지별 개별 생성
  • • 음성 스타일 선택
  • • 일괄 생성 (병렬)

F4. 학습 게임 (Educational Games)

단어 퀴즈
단어 조립
메모리 매치

  • • 이미지 설정: imageSettings
  • • 현재 작업: currentStorybook
