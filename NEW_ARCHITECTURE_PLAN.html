의존성 규칙 (Dependency Rule)

Presentation Application Domain Infrastructure
  • 외부 레이어는 내부 레이어를 의존할 수 있음
  • 내부 레이어는 외부 레이어를 의존하면 안 됨
  • Domain Layer는 순수한 TypeScript로 작성 (프레임워크 독립)

4. 적용할 디자인 패턴

Repository Pattern

데이터 접근 로직을 추상화하여 비즈니스 로직과 분리 
// Domain Layer - Interface
interface IStorybookRepository {
  findById(id: string): Promise<Storybook | null>;
  save(storybook: Storybook): Promise<void>;
  delete(id: string): Promise<void>;
}

// Infrastructure Layer - Implementation
class R2StorybookRepository implements IStorybookRepository {
  async findById(id: string) {
    // R2 API 호출
  }
}
장점: DB 변경 시 Repository만 교체하면 됨

Factory Pattern

객체 생성 로직을 캡슐화하여 복잡한 생성 과정 단순화 
// 동화책 생성 팩토리
class StorybookFactory {
  static create(params: CreateStorybookParams): Storybook {
    return new Storybook({
      id: generateId(),
      title: params.title,
      pages: params.pages.map(p => Page.create(p)),
      createdAt: new Date()
    });
  }
  
  static duplicate(original: Storybook): Storybook {
    return new Storybook({
      ...original,
      id: generateId(),
      title: `${original.title} (복사본)`
    });
  }
}
장점: 생성 로직 중앙 관리, 일관성 보장

Observer Pattern (Event Bus)

느슨한 결합으로 컴포넌트 간 통신 
// 이벤트 정의
type DomainEvent = 
  | { type: 'STORYBOOK_CREATED'; payload: Storybook }
  | { type: 'PAGE_ADDED'; payload: { bookId: string; page: Page } };

// Event Bus
class EventBus {
  private listeners = new Map();
  
  on(event: string, handler: Function) {
    // 구독
  }
  
  emit(event: DomainEvent) {
    // 발행
  }
}
장점: 모듈 간 결합도 최소화

Command Pattern

작업을 객체로 캡슐화하여 실행 취소/재실행 가능 
// 커맨드 인터페이스
interface Command {
  execute(): Promise<void>;
  undo(): Promise<void>;
}

// 구체적인 커맨드
class UpdateTitleCommand implements Command {
  constructor(
    private bookId: string,
    private newTitle: string,
    private oldTitle: string
  ) {}
  
  async execute() {
    await this.repository.updateTitle(this.bookId, this.newTitle);
  }
  
  async undo() {
    await this.repository.updateTitle(this.bookId, this.oldTitle);
  }
}
장점: Undo/Redo 기능 구현 용이

Strategy Pattern

알고리즘을 캡슐화하여 런타임에 교체 가능 
// 이미지 생성 전략
interface ImageGenerationStrategy {
  generate(prompt: string): Promise<string>;
}

class GeminiStrategy implements ImageGenerationStrategy {
  async generate(prompt: string) {
    // Gemini API 호출
  }
}

class ImageGenerator {
  constructor(private strategy: ImageGenerationStrategy) {}
  
  setStrategy(strategy: ImageGenerationStrategy) {
    this.strategy = strategy;
  }
}
장점: AI 모델 변경 시 유연하게 대응

Adapter Pattern

외부 API를 내부 인터페이스에 맞게 변환 
// 내부 인터페이스
interface IAIService {
  generateText(prompt: string): Promise<string>;
}

// Gemini API Adapter
class GeminiAdapter implements IAIService {
  async generateText(prompt: string) {
    // Gemini의 복잡한 API를 단순화
    const result = await geminiClient.generateContent({
      contents: [{ role: 'user', parts: [{ text: prompt }] }]
    });
    return result.response.text();
  }
}
장점: 외부 API 변경에 영향 최소화

Singleton Pattern

전역적으로 하나의 인스턴스만 존재하도록 보장 
// API 클라이언트 싱글톤
class GeminiClient {
  private static instance: GeminiClient;
  
  private constructor() {
    // private constructor
  }
  
  static getInstance(): GeminiClient {
    if (!GeminiClient.instance) {
      GeminiClient.instance = new GeminiClient();
    }
    return GeminiClient.instance;
  }
}
장점: API 클라이언트 중복 생성 방지

Decorator Pattern

기존 객체에 동적으로 새로운 기능 추가 
// 로깅 데코레이터
function withLogging(target: any) {
  return class extends target {
    async execute(...args: any[]) {
      console.log(`Executing ${target.name}`);
      const result = await super.execute(...args);
      console.log(`Completed ${target.name}`);
      return result;
    }
  };
}

// 사용
@withLogging
class CreateStorybookUseCase { ... }
장점: 횡단 관심사(로깅, 캐싱) 분리

Domain Layer 예시 

// domain/entities/Storybook.ts
export class Storybook {
  private constructor(
    public readonly id: StorybookId,
    public title: Title,
    public pages: Page[],
    public coverImage?: ImageUrl
  ) {}

  static create(params: CreateStorybookParams): Storybook {
    // 유효성 검증
    if (!params.title) {
      throw new ValidationError('제목은 필수입니다');
    }
    
    return new Storybook(
      StorybookId.generate(),
      Title.create(params.title),
      []
    );
  }

  addPage(page: Page): void {
    this.pages.push(page);
    // 도메인 이벤트 발행
    DomainEvents.raise(new PageAddedEvent(this.id, page));
  }

  duplicate(): Storybook {
    return new Storybook(
      StorybookId.generate(),
      Title.create(`${this.title.value} (복사본)`),
      this.pages.map(p => p.clone()),
      this.coverImage
    );
  }
}

Application Layer 예시 

// application/usecases/storybook/CreateStorybookUseCase.ts
export class CreateStorybookUseCase {
  constructor(
    private storybookRepo: IStorybookRepository,
    private eventBus: EventBus
  ) {}

  async execute(params: CreateStorybookParams): Promise<Storybook> {
    // 1. 도메인 엔티티 생성
    const storybook = Storybook.create(params);
    
    // 2. 저장
    await this.storybookRepo.save(storybook);
    
    // 3. 이벤트 발행
    this.eventBus.emit({
      type: 'STORYBOOK_CREATED',
      payload: storybook
    });
    
    return storybook;
  }
}

Repository Implementation 

// infrastructure/repositories/R2StorybookRepository.ts
export class R2StorybookRepository implements IStorybookRepository {
  constructor(private r2Client: R2Client) {}

  async findById(id: StorybookId): Promise<Storybook | null> {
    const data = await this.r2Client.get(`storybook-${id.value}.json`);
    if (!data) return null;
    
    // 도메인 엔티티로 변환
    return StorybookMapper.toDomain(data);
  }

  async save(storybook: Storybook): Promise<void> {
    // 도메인 엔티티를 저장 형식으로 변환
    const data = StorybookMapper.toPersistence(storybook);
    await this.r2Client.put(
      `storybook-${storybook.id.value}.json`,
      data
    );
  }
}

5.1. API Routes (Hono)

// storybook.routes.ts
import { Hono } from 'hono';

const app = new Hono();

app.get('/storybooks', async (c) => {
  const query = new GetStorybooksQuery();
  const storybooks = await query.execute();
  return c.json(storybooks);
});

app.post('/storybooks', async (c) => {
  const body = await c.req.json();
  const useCase = new CreateStorybookUseCase(...);
  const storybook = await useCase.execute(body);
  return c.json(storybook, 201);
});
