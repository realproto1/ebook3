현재 시스템의 문제점

⚠️ 핵심 문제

server.js (3600줄)과 app.js (4000줄)에 모든 로직이 집중되어 있어 유지보수가 매우 어렵고, 버그 발생 시 원인 파악과 수정에 오랜 시간이 소요됩니다.

1️⃣ 코드 품질 문제
문제 영향 심각도
거대한 단일 파일 server.js 3600줄, app.js 4000줄 🔴 매우 높음
책임 분리 부족 한 함수에 여러 역할 혼재 🟡 높음
타입 안정성 부족 런타임 에러 빈번 발생 🟡 높음
중복 코드 다수 유사 로직이 여러 곳에 산재 🟡 높음
전역 상태 남용 예상치 못한 부작용 발생 🟢 중간
2️⃣ 구조적 문제
  • 의존성 관리 불가: 모듈 간 강한 결합으로 테스트 어려움
  • 확장성 부족: 새 기능 추가 시 기존 코드 대폭 수정 필요
  • 재사용성 낮음: 컴포넌트 독립성 부족
  • 디버깅 어려움: 긴 함수와 복잡한 호출 체인
  • 협업 불가: 파일 단위 충돌 빈번
3️⃣ 성능 문제
  • 번들 크기 과다: 단일 파일로 인한 초기 로딩 지연
  • 메모리 누수: 이벤트 리스너 정리 미흡
  • 불필요한 재렌더링: 전체 UI 재생성
  • API 호출 최적화 부족: 중복 요청 발생

개선 목표

✨ 핵심 목표

모듈화된 TypeScript 기반 아키텍처로 완전히 재설계하여, 유지보수성 향상, 버그 감소, 개발 속도 증가를 달성합니다.

📦 모듈화

단일 파일을 기능별 모듈로 분리하여 각 파일이 100-300줄을 유지합니다. 명확한 책임 분리로 코드 이해도를 높입니다.

🔒 타입 안정성

TypeScript로 마이그레이션하여 컴파일 시점에 에러를 발견하고, IDE의 자동완성과 리팩토링 기능을 활용합니다.

🏗️ Clean Architecture

계층별 명확한 분리로 비즈니스 로직을 프레임워크와 독립적으로 유지하여 테스트와 유지보수를 용이하게 합니다.

🎯 SOLID 원칙

단일 책임, 개방-폐쇄, 리스코프 치환, 인터페이스 분리, 의존성 역전 원칙을 준수하여 견고한 설계를 구현합니다.

🧪 테스트 가능

의존성 주입과 인터페이스 기반 설계로 단위 테스트와 통합 테스트를 쉽게 작성할 수 있습니다.

⚡ 성능 최적화

코드 스플리팅, 지연 로딩, 메모이제이션 등을 활용하여 초기 로딩 속도와 런타임 성능을 개선합니다.

시스템 아키텍처

🏛️ Clean Architecture + Hexagonal Architecture

비즈니스 로직을 중심에 두고, 외부 프레임워크와 라이브러리를 교체 가능하게 설계합니다. 의존성은 항상 안쪽(도메인)을 향하도록 구성합니다.

의존성 흐름 규칙
  1. 안쪽 방향: 의존성은 항상 바깥 → 안쪽으로만 흐름
  2. 인터페이스 분리: Domain은 Infrastructure를 직접 의존하지 않고 인터페이스를 통해 접근
  3. 독립성 보장: Domain과 Application은 프레임워크에 독립적
  4. 의존성 역전: 구체 클래스가 아닌 추상화(인터페이스)에 의존

적용할 디자인 패턴

1️⃣ 생성 패턴 (Creational Patterns)

Factory Pattern

목적: 객체 생성 로직을 캡슐화하여 코드의 유연성과 재사용성 향상

// src/domain/factories/StorybookFactory.ts
export interface IStorybookFactory {
  createStorybook(data: CreateStorybookDTO): Storybook;
  createCharacter(data: CreateCharacterDTO): Character;
  createPage(data: CreatePageDTO): Page;
}

export class StorybookFactory implements IStorybookFactory {
  createStorybook(data: CreateStorybookDTO): Storybook {
    return new Storybook({
      id: generateId(),
      title: data.title,
      targetAge: data.targetAge,
      artStyle: data.artStyle,
      characters: [],
      pages: [],
      createdAt: new Date(),
    });
  }
}

사용 위치: Storybook, Character, Page, Vocabulary 등 복잡한 도메인 객체 생성

Builder Pattern

목적: 복잡한 객체를 단계별로 생성하여 가독성과 유지보수성 향상

// src/domain/builders/StorybookBuilder.ts
export class StorybookBuilder {
  private storybook: Partial<Storybook> = {};

  withTitle(title: string): this {
    this.storybook.title = title;
    return this;
  }

  withCharacters(characters: Character[]): this {
    this.storybook.characters = characters;
    return this;
  }

  build(): Storybook {
    return new Storybook(this.storybook as StorybookData);
  }
}

사용 위치: 테스트 데이터 생성, 복잡한 프롬프트 빌드

Singleton Pattern

목적: 애플리케이션 전역에서 단일 인스턴스 보장 (DI Container, Config)

// src/infrastructure/config/AppConfig.ts
export class AppConfig {
  private static instance: AppConfig;

  private constructor() {}

  public static getInstance(): AppConfig {
    if (!AppConfig.instance) {
      AppConfig.instance = new AppConfig();
    }
    return AppConfig.instance;
  }
}

사용 위치: Storybook, Character, Vocabulary 등 모든 엔티티의 영속성 관리

Adapter Pattern

목적: 외부 API를 내부 인터페이스에 맞게 변환

// src/domain/ports/IAIImageGenerator.ts
export interface IAIImageGenerator {

}

// src/infrastructure/adapters/GeminiAdapter.ts
export class GeminiAdapter implements IAIImageGenerator {

사용 위치: Gemini AI, Google TTS, R2 Storage 등 외부 서비스 통합

Decorator Pattern

목적: 기존 기능에 새로운 기능을 동적으로 추가 (로깅, 캐싱, 재시도)

// src/application/decorators/LoggingDecorator.ts
export class LoggingImageGenerator implements IAIImageGenerator {
  constructor(private wrapped: IAIImageGenerator) {}

  async generate(prompt: string, refs: string[]): Promise<string> {
    console.log(`Generating image: ${prompt}`);
    const result = await this.wrapped.generate(prompt, refs);
    console.log(`Image generated successfully`);
    return result;
  }
}

3️⃣ 행위 패턴 (Behavioral Patterns)

Command Pattern

목적: 요청을 객체로 캡슐화하여 실행 취소, 재실행, 큐잉 가능

// src/application/commands/GenerateStorybookCommand.ts
export interface ICommand<T> {
  execute(): Promise<T>;
}

export class GenerateStorybookCommand implements ICommand<Storybook> {
  constructor(
    private data: CreateStorybookDTO,
    private service: StorybookService
  ) {}

  async execute(): Promise<Storybook> {
    return await this.service.generateStorybook(this.data);
  }
}

사용 위치: 동화책 생성, 이미지 생성, 번역 등 복잡한 작업

Strategy Pattern

목적: 알고리즘군을 캡슐화하여 런타임에 전환 가능

// src/domain/strategies/IImageGenerationStrategy.ts

// src/application/use-cases/storybook/CreateStorybookUseCase.ts
export class CreateStorybookUseCase {
  constructor(
    private repository: IStorybookRepository,
    private factory: IStorybookFactory,
    private aiGenerator: IAIImageGenerator
  ) {}

  async execute(dto: CreateStorybookDTO): Promise<Storybook> {
    // 1. 검증
    this.validate(dto);

    // 2. 도메인 객체 생성
    const storybook = this.factory.createStorybook(dto);

    // 3. AI 스토리 생성
    const story = await this.aiGenerator.generateStory(dto);
    storybook.setPages(story.pages);

    // 4. 저장
    await this.repository.save(storybook);

    // 5. 이벤트 발행
    this.publishEvent(new StorybookCreatedEvent(storybook.id));

    return storybook;
  }
}

      throw new DomainError('캐릭터는 최대 10개까지 추가 가능');
    }
    this._characters.push(character);
  }

    if (!this.isPublishable()) {

    }
    this._isPublic = true;
    this._publishedAt = new Date();

    return this._coverImage !== undefined &&
           this._pages.length > 0;
  }
}

// src/presentation/web/components/common/BaseComponent.ts
export abstract class BaseComponent<T = any> {
  protected element: HTMLElement;
  protected state: T;

  constructor(
    protected container: HTMLElement,
    initialState: T
  ) {
    this.state = initialState;
    this.element = this.createElement();
    this.attachEventListeners();
    this.render();
  }

  protected abstract template(): string;
  protected abstract attachEventListeners(): void;

  protected setState(newState: Partial<T>): void {
    this.state = { ...this.state, ...newState };
    this.render();
  }

  protected render(): void {
    this.element.innerHTML = this.template();
    this.attachEventListeners();
  }

  public mount(): void {
    this.container.appendChild(this.element);
  }

  public unmount(): void {
    this.element.remove();
  }
}

interface StorybookCardState {
  storybook: Storybook;
  isSelected: boolean;
}

export class StorybookCard extends BaseComponent<StorybookCardState> {
  protected template(): string {
    const { storybook, isSelected } = this.state;
    
    return `
      <div class="storybook-card ${isSelected ? 'selected' : ''}">
        <img src="${storybook.coverImage}" alt="${storybook.title}">
        <h3>${storybook.title}</h3>
        <p>${storybook.targetAge}세 | ${storybook.pages.length}페이지</p>
        <button class="edit-btn">편집</button>
        <button class="delete-btn">삭제</button>
      </div>
    `;
  }

  protected attachEventListeners(): void {
    const editBtn = this.element.querySelector('.edit-btn');
    editBtn?.addEventListener('click', () => this.onEdit());

    const deleteBtn = this.element.querySelector('.delete-btn');
    deleteBtn?.addEventListener('click', () => this.onDelete());
  }

  private onEdit(): void {
    this.emit('edit', this.state.storybook);
  }

  private onDelete(): void {
    this.emit('delete', this.state.storybook.id);
  }
}

Store 패턴
// src/presentation/web/state/StorybookStore.ts
interface StorybookState {
  storybooks: Storybook[];
  selectedId: string | null;
  isLoading: boolean;
}

export class StorybookStore {
  private state: StorybookState = {
    storybooks: [],
    selectedId: null,
    isLoading: false
  };

  private listeners: Set<Function> = new Set();

  public subscribe(listener: Function): void {
    this.listeners.add(listener);
  }

  public setState(newState: Partial<StorybookState>): void {
    this.state = { ...this.state, ...newState };
    this.notify();
  }

  private notify(): void {
    this.listeners.forEach(listener => listener(this.state));
  }

  public getState(): StorybookState {
    return this.state;
  }
}
