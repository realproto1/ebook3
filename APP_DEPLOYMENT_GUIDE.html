1. 개요 및 전체 프로세스

현재 프로젝트 상태

  • 프로젝트명: 탱고북 (동화책 자동 생성기)
  • 기술 스택: Node.js + Hono + Cloudflare R2
  • 데이터베이스: Cloudflare R2 (Object Storage)
  • 현재 배포: Sandbox 환경
  • 목표 배포: Railway (프로덕션)

전체 배포 프로세스

1 Railway 배포 - 웹 앱을 Railway에 배포하여 프로덕션 URL 확보
2 Android APK 생성 - PWABuilder 또는 Bubblewrap을 사용하여 APK 생성
3 iOS App 생성 - PWABuilder로 Xcode 프로젝트 생성 (Mac 필요)
4 앱스토어 배포 - Google Play Store 및 Apple App Store 등록
💡 핵심 요약:
  • Railway: 웹 앱 호스팅 (무료 티어 $5 크레딧/월)
  • Android: PWABuilder 사용 (무료, Google Play $25 평생)
  • iOS: Mac + Apple Developer 계정 필요 ($99/년)

2. Railway 배포

2.1. Railway 계정 생성

  1. https://railway.app 접속
  2. "Start a New Project" 클릭
  3. GitHub 계정으로 로그인

2.2. 프로젝트 설정

GitHub 연동

1 Railway에서 "Deploy from GitHub repo" 선택
2 realproto1/ebook3 레포지토리 선택
3 자동으로 배포 시작

환경 변수 설정

# Railway Dashboard → Variables 탭

# Cloudflare R2 설정
R2_ACCOUNT_ID=your_account_id
R2_ACCESS_KEY_ID=your_access_key
R2_SECRET_ACCESS_KEY=your_secret_key
R2_BUCKET_NAME=storybook-images
R2_PUBLIC_URL=https://pub-554d78bf0f2346cfb850060ac23280a7.r2.dev

# Gemini API
GEMINI_API_KEY=your_gemini_api_key

# 포트 설정
PORT=3000

빌드 설정

Railway는 자동으로 package.json을 감지하여 빌드합니다.

자동 감지되는 설정:
  • Build Command: npm install
  • Start Command: npm start 또는 node server.js

2.3. 도메인 설정

Railway 기본 도메인

https://your-app.railway.app

커스텀 도메인 연결 (선택)

  1. Settings → Domains 탭
  2. "Custom Domain" 클릭
  3. 도메인 입력 (예: tangobook.com)
  4. DNS 레코드 설정: 
    CNAME    @    your-app.railway.app

3. Android APK 생성

3.1. 사전 준비

필요한 파일

  • ✅ manifest.json (이미 있음)
  • ⚠️ PNG 아이콘 (512×512px) - SVG를 PNG로 변환 필요
  • ❌ assetlinks.json - 새로 생성 필요

아이콘 준비

1 512×512px PNG 아이콘 생성
2 public/icon-512.png로 저장
3 manifest.json 업데이트: 
{
  "icons": [
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    }
  ]
}

3.2. PWABuilder 사용 (추천) ⭐

Step 1: PWABuilder 접속

1 https://www.pwabuilder.com 접속
2 Railway URL 입력: 
https://your-app.railway.app
3 "Start" 클릭

Step 2: Manifest 확인

  • Name: ✅ 탱고북 동화책 뷰어
  • Short Name: ✅ 탱고북
  • Start URL: ✅ /viewer.html
  • Display: ✅ standalone
  • Icons: ⚠️ PNG로 교체 필요

Step 3: Android 패키지 설정

Package ID: com.tangobook.app
App Name: 탱고북
Launcher Name: 탱고북
Host: your-app.railway.app
Start URL: /viewer.html

Step 4: assetlinks.json 생성

# public/.well-known/assetlinks.json
[{
  "relation": ["delegate_permission/common.handle_all_urls"],
  "target": {
    "namespace": "android_app",
    "package_name": "com.tangobook.app",
    "sha256_cert_fingerprints": [
      "SHA256_FINGERPRINT_FROM_PWABUILDER"
    ]
  }
}]

Step 5: APK 다운로드

1 "Generate" 클릭
2 APK 파일 다운로드:
  • app-release-signed.apk - Google Play 배포용
  • app-release-unsigned.apk - 테스트용

3.3. Google Play Store 등록

개발자 계정 생성

1 Google Play Console 접속
2 개발자 계정 등록 ($25 평생)

앱 등록

  1. "앱 만들기" 클릭
  2. 앱 정보 입력:
    • 앱 이름: 탱고북
    • 기본 언어: 한국어
    • 앱 카테고리: 교육
  3. 앱 콘텐츠 등급 설정
  4. 개인정보처리방침 URL 입력
  5. APK 업로드 (프로덕션 트랙)
  6. 스토어 등록정보 작성:
    • 앱 설명
    • 스크린샷 (최소 2개)
    • 아이콘 (512×512px)
  7. 검토 제출
📝 검토 기간: 일반적으로 1~3일 소요

3.4. Bubblewrap CLI (대안)

# 설치
npm install -g @bubblewrap/cli

# 초기화
bubblewrap init --manifest https://your-app.railway.app/manifest.json

# 빌드
bubblewrap build

# APK 위치
./app-release-signed.apk
⚠️ 주의: Bubblewrap은 Java 8 이상 필요

4. iOS App 생성

❌ iOS 필수 요구사항:
  • Mac 컴퓨터 (Xcode 빌드용)
  • Apple Developer 계정 ($99/년)
  • Xcode (Mac App Store에서 무료)

4.1. Mac이 있는 경우

방법 1: PWABuilder (추천)

1 PWABuilder에서 iOS 옵션 선택
2 Xcode 프로젝트 다운로드 (TangoBook.zip)
3 Mac에서 압축 해제 및 Xcode로 열기
4 Apple Developer 계정 연결
5 서명 설정 (Signing & Capabilities)
6 Archive 빌드 → IPA Export

방법 2: Capacitor

# 프로젝트에서 실행
npm install @capacitor/core @capacitor/cli
npm install @capacitor/ios

# 초기화
npx cap init

# iOS 플랫폼 추가
npx cap add ios

# 빌드 및 복사
npm run build
npx cap copy

# Xcode 열기
npx cap open ios

4.2. Mac이 없는 경우

옵션 1: Safari PWA (무료) ⭐ 추천

  3. 공유 버튼 → "홈 화면에 추가"
  4. 완료!
장점:

7. 문제 해결

Railway 배포 문제

빌드 실패

증상: "Build failed" 에러

해결:
  • 환경 변수 확인 (R2, Gemini API)
  • package.json의 start 스크립트 확인
  • 로그에서 에러 메시지 확인

환경 변수 인식 안됨

증상: "R2_ACCOUNT_ID is not defined"

해결:
  • Railway Dashboard → Variables 탭 확인
  • 변수 이름 대소문자 정확히 입력
  • 재배포 (Redeploy)

Android APK 문제

assetlinks.json 404

증상: TWA 검증 실패

해결: 
# 파일 위치 확인
public/.well-known/assetlinks.json

# URL 확인
https://your-app.railway.app/.well-known/assetlinks.json

APK 설치 안됨

증상: "App not installed"

해결:
  • 기존 버전 삭제 후 재설치
  • "출처 불명 앱 설치 허용" 활성화
  • APK 서명 확인

iOS 빌드 문제

Xcode 서명 에러

증상: "Code signing is required"

해결:
  • Signing & Capabilities → Team 선택
  • Bundle Identifier 확인
  • Provisioning Profile 재생성

Mac 없을 때

✅ 최선의 대안:
  • Safari PWA 사용 (무료, 즉시 가능)
  • 사용자에게 "홈 화면에 추가" 안내
  • App Store 앱과 유사한 경험 제공

PWA 문제

manifest.json 인식 안됨

증상: PWA 설치 프롬프트 안 뜸

해결:
  • HTTPS 확인 (Railway는 기본 제공)
  • manifest.json 경로 확인
  • 아이콘 최소 192×192px 이상
  • start_url, scope 확인

일반 문제

R2 이미지 로딩 안됨

증상: 동화책 이미지가 안 보임

해결:
  • R2 Public URL 확인
  • CORS 설정 확인
  • 브라우저 콘솔에서 에러 확인

API 요청 실패

증상: "Failed to fetch"

해결:
  • Railway URL이 올바른지 확인
  • CORS 설정 확인
  • API 엔드포인트 경로 확인
