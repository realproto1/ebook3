핵심 원칙

  • ✅ NO TEXT: 모든 이미지에 텍스트 절대 금지 (순수 일러스트레이션)
  • ✅ 일관성: 캐릭터 외형, 아트 스타일, 색상 팔레트 유지
  • ✅ 타겟 연령: 4-8세 어린이 적합 디자인
  • ✅ 고품질: 전문적인 어린이 책 일러스트레이션 수준

1. 표지 이미지 프롬프트

함수 시그니처

function buildCoverPrompt(storybook) { // 표지 이미지 생성을 위한 프롬프트 반환 return prompt; }

입력 파라미터

  • storybook.title - 동화책 제목
  • storybook.theme - 테마/주제
  • storybook.artStyle - 그림체 스타일
  • storybook.characters - 캐릭터 배열

프롬프트 구조

Create a beautiful, professional book cover illustration for a children's storybook. **Book Title:** ${title} **Theme:** ${theme} **Art Style:** ${artStyle} **Main Characters:** ${characters} **Cover Requirements:** - Eye-catching, vibrant illustration that captures the story's essence - Show the main characters in an engaging scene - Magical, inviting atmosphere suitable for children ages 4-8 - Professional book cover quality - Composition suitable for a vertical book cover layout **DO NOT include:** - Any text, title, or letters on the cover - Book spine or binding elements - Just pure illustration Create a captivating cover illustration that makes children want to read this story!

핵심 포인트

  • ✅ 세로 레이아웃 - 책 표지 형식
  • ✅ 캐릭터 등장 - 주요 캐릭터 모두 표시
  • ✅ 텍스트 금지 - 제목, 글자 일체 포함 안 됨
  • ✅ 매력적인 장면 - 어린이의 호기심 자극

2. 캐릭터 레퍼런스 시트 프롬프트

함수 시그니처

function buildCharacterPrompt( description, artStyle, settings, isRegeneration = false ) { // 캐릭터 레퍼런스 시트 생성 프롬프트 return prompt; }

입력 파라미터

  • description - 캐릭터 설명 (외형, 의상, 특징)
  • artStyle - 그림체 스타일
  • settings.aspectRatio - 이미지 비율
  • settings.enforceNoText - 텍스트 강제 금지
  • settings.additionalPrompt - 추가 지침
  • isRegeneration - 재생성 모드 (기존 이미지 있을 때)

프롬프트 구조

Create a professional character design reference sheet for a children's storybook character. **Character Description:** ${description} **Art Style:** ${artStyle} style for children's book illustration, suitable for ages 4-8. **Reference Sheet Layout:** 1. **Center (Front View):** Full-body front view in a neutral standing pose 2. **Side Views:** Three-quarter view and side profile 3. **Expressions:** Three different facial expressions (happy, surprised, thoughtful) 4. **Details:** Clear, consistent details of clothing, colors, and distinctive features **Background:** Clean white background with subtle grid or guidelines **Art Quality:** High-detail, professional children's book illustration quality **Image Aspect Ratio:** ${settings.aspectRatio} **NO TEXT:** Do NOT include any text, labels, words, letters, or captions

재생성 모드 (isRegeneration = true)

🔄 Regeneration Mode

기존 캐릭터 이미지가 있을 때 일관성을 유지하면서 수정

**🔄 REGENERATION MODE - CRITICAL INSTRUCTIONS:** STEP 1: CAREFULLY ANALYZE the reference image - Current character design, facial features, body proportions - Exact colors (clothing, hair, skin tone, accessories) - Art style, line work, and shading technique STEP 2: MAINTAIN these exact elements - Core character design and recognizability - Color palette (unless explicitly changed) - Art style consistency STEP 3: ONLY modify what is explicitly mentioned in the updated description **Priority Order:** 1st: Reference Image (base design) 2nd: Updated Character Description (modifications only) 3rd: Art Style (already established in reference)

레퍼런스 시트가 중요한 이유

  • ✅ 일관성 보장 - 모든 페이지에서 동일한 캐릭터 외형
  • ✅ 다각도 뷰 - 정면, 측면, 3/4 뷰로 완전한 이해
  • ✅ 표정 다양성 - 다양한 감정 표현 가능
  • ✅ 디테일 정확성 - 의상, 색상, 특징 명확히 기록

3. 페이지 삽화 프롬프트 (가장 복잡)

🎨 가장 정교한 프롬프트 시스템

페이지 삽화는 스토리 맥락, 캐릭터 일관성, 장면 구조를 모두 고려하는 가장 복잡한 프롬프트입니다.

함수 시그니처

function buildIllustrationPrompt( page, artStyle, characterReferences, settings, editNote = '' ) { // 페이지 삽화 생성 프롬프트 // 자동 캐릭터 필터링, 스토리 컨텍스트, 재생성 모드 지원 return prompt; }

입력 파라미터

  • page.pageNumber - 페이지 번호
  • page.text - 페이지 텍스트
  • page.scene_description - 장면 설명
  • page.scene_structure - 장면 구조 (캐릭터, 배경, 분위기)
  • page.illustrationImage - 기존 이미지 (재생성 시)
  • artStyle - 그림체 스타일
  • characterReferences - 캐릭터 레퍼런스 배열
  • settings - 이미지 설정
  • editNote - 수정 요청 (선택)

🎯 핵심 기능

1. 자동 캐릭터 필터링

// 페이지에 등장하는 캐릭터만 자동 감지 const allText = `${pageText} ${sceneCharacters} ${editNote}`; const relevantCharacters = characterReferences.filter(char => { return allText.includes(char.name.toLowerCase()); }); console.log(`전체 ${characterReferences.length}명 → 등장 ${filteredCharacters.length}명`);

2. 스토리 컨텍스트

  • • 최근 3페이지 포함 - 타임아웃 방지
  • • 이전 페이지 참조 - 시각적 일관성
  • • 현재 페이지 강조 - 컨텍스트 제공
  • • 재생성 시 생략 - editNote 있을 때

3. 캐릭터 일관성

  • • PIXEL-FOR-PIXEL - 레퍼런스 정확히 재현
  • • 얼굴 특징 - 완벽한 매칭
  • • 의상/색상 - 동일하게 유지
  • • 비율/자세 - 일관된 표현

4. 재생성 모드

  • • 수정 요청 우선 - editNote 기반
  • • 레퍼런스 유지 - 캐릭터 외형
  • • 스타일 일관성 - 아트 스타일
  • • 비율 고정 - aspect ratio 유지

프롬프트 구조 (기본 모드)

Create a beautiful, professional illustration for a children's storybook page. **RECENT STORY CONTEXT:** // 최근 3페이지 텍스트 Page 1: ${page1Text} Page 2: ${page2Text} Page 3: ${page3Text} **CURRENT PAGE ${pageNumber}:** ${currentPageText} **🎨 PREVIOUS PAGE REFERENCE:** I have provided the illustration from the immediately previous page as a reference image. Character Name: ${description} - CRITICAL: Use reference image to ensure ABSOLUTE PIXEL-PERFECT consistency **Art Style:** ${artStyle} style for children's book illustration **Image Aspect Ratio:** ${aspectRatio} **Composition:** Warm, inviting scene suitable for a storybook spread **🎯 DIRECTIONAL CONSISTENCY:** Analyze the previous page's character positions and maintain consistent left-right orientation **Lighting & Atmosphere:** Soft, warm lighting with gentle shadows **Color Palette:** Vibrant, cheerful colors appropriate for children ages 4-8 **Art Quality:** High-detail, professional quality with painterly texture **Target Audience:** Children ages 4-8 **CRITICAL - NO TEXT:** Do NOT include ANY text, labels, words, letters, captions, titles, speech bubbles, or text overlays. Absolutely NO TEXT of any kind.

재생성 모드 (editNote 있음)

🔄 Regeneration with Modification

**🔄 REGENERATION MODE - CRITICAL INSTRUCTIONS:** STEP 1 - ANALYZE REFERENCE IMAGES: 1. Current illustration (what it looks like now) 2. Character reference sheets (how characters should look) 3. Selected reference pages (additional context) STEP 2 - READ MODIFICATION REQUEST: User's modification request: "${editNote}" **YOUR TASK:** - CREATE the scene based on this modification request - USE the reference images to maintain: • Character visual consistency • Art style and color palette • Overall composition quality - IGNORE the original scene description - FOCUS on what the user wants to see **⚠️ CRITICAL REQUIREMENTS:** • Characters MUST be visually IDENTICAL to reference sheets • Follow the modification request (not the original scene description) • Reference images are for VISUAL STYLE only, not for scene content **Priority Order for REGENERATION:** 1st: User's Modification Request (what to create) 2nd: Character Reference Sheets (how characters look) 3rd: Reference Images (visual style guide) 4th: Art Style (maintain consistency) **IGNORE these during regeneration:** ❌ Original scene description (shown below for reference only) ❌ Original scene structure (outdated)

페이지 삽화 프롬프트의 장점

  • ✅ 자동 최적화 - 페이지에 등장하는 캐릭터만 포함 (토큰 절약)
  • ✅ 스토리 연속성 - 이전 페이지와 자연스럽게 연결
  • ✅ 시각적 일관성 - 캐릭터 레퍼런스로 픽셀 단위 정확도
  • ✅ 유연한 수정 - editNote로 특정 부분만 변경 가능
  • ✅ 타임아웃 방지 - 재생성 시 불필요한 컨텍스트 생략

4. 이미지 설정 옵션 (settings)

기본 설정

let imageSettings = { aspectRatio: '16:9', enforceNoText: true, enforceCharacterConsistency: true, additionalPrompt: '', imageQuality: 'high', // 모델 선택 characterModel: 'gemini-3-pro-image-preview', keyObjectModel: 'gemini-3-pro-image-preview', illustrationModel: 'gemini-3-pro-image-preview', vocabularyModel: 'gemini-3-pro-image-preview', coverModel: 'gemini-3-pro-image-preview' };

aspectRatio

이미지 비율 (16:9, 4:3, 1:1 등)

enforceNoText

true: 텍스트 강력 금지
false: 일반 텍스트 금지

enforceCharacterConsistency

true: 픽셀 단위 캐릭터 일관성
false: 기본 일관성

additionalPrompt

추가 지침 (선택 사항)

5. 프롬프트 작성 팁 & 베스트 프랙티스

DO (권장 사항)

  • ✅ 명확한 설명: 캐릭터/장면을 구체적으로 설명
  • ✅ 일관성 유지: 모든 이미지에 동일한 아트 스타일
  • ✅ 레퍼런스 사용: 캐릭터는 반드시 레퍼런스 시트 생성
  • ✅ 컨텍스트 제공: 스토리 흐름을 프롬프트에 포함
  • ✅ 연령 적합성: 4-8세 어린이 타겟 명시
  • ✅ 감정 표현: 분위기, 조명, 색상으로 감정 전달
  • ✅ 방향성 일관성: 캐릭터 위치/방향 유지

DON'T (피해야 할 것)

  • ❌ 텍스트 포함: 절대로 글자/제목/라벨 허용 안 함
  • ❌ 모호한 설명: "예쁜", "좋은" 같은 추상적 표현
  • ❌ 레퍼런스 없음: 캐릭터 일관성 보장 불가
  • ❌ 너무 긴 프롬프트: 타임아웃 발생 위험
  • ❌ 상충되는 지침: 모순된 요구사항
  • ❌ 부적절한 내용: 어린이 부적합 요소
  • ❌ 비율 무시: 재생성 시 aspect ratio 변경

프로 팁

1. 캐릭터 필터링 활용

등장하지 않는 캐릭터는 자동으로 제외되어 토큰 절약

2. 이전 페이지 참조

바로 전 페이지 이미지를 레퍼런스로 제공해 일관성 극대화

3. 재생성 모드 활용

editNote로 특정 부분만 수정해 효율적인 재생성

4. 타임아웃 방지

재생성 시 스토리 컨텍스트 자동 생략으로 빠른 처리

6. 실전 사용 예시

예시 1: 표지 생성

const storybook = { title: '어린 왕자', theme: '우정과 모험', artStyle: '수채화 스타일', characters: [ { name: '어린 왕자' }, { name: '여우' } ] }; const coverPrompt = buildCoverPrompt(storybook); // → "Create a beautiful, professional book cover... // Book Title: 어린 왕자 // Theme: 우정과 모험...

예시 2: 캐릭터 레퍼런스 생성

const characterPrompt = buildCharacterPrompt( '금발 소년, 파란색 왕자 옷, 호기심 많은 표정', '수채화 스타일', { aspectRatio: '16:9', enforceNoText: true, additionalPrompt: '별이 반짝이는 배경' }, false // 첫 생성 );

예시 3: 페이지 삽화 생성

const page = { pageNumber: 5, text: '어린 왕자는 여우를 만났습니다.', scene_description: '사막에서 어린 왕자와 여우가 만나는 장면', scene_structure: { characters: '어린 왕자, 여우', background: '황금빛 사막, 석양', atmosphere: '따뜻하고 감동적인' } }; const illustrationPrompt = buildIllustrationPrompt( page, '수채화 스타일', characterReferences, imageSettings, '' // editNote 없음 ); // 자동으로: // - 어린 왕자, 여우 캐릭터만 필터링 // - 최근 3페이지 컨텍스트 포함 // - 이전 페이지 이미지 참조
