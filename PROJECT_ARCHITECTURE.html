프로젝트 개요

🎯 프로젝트 목적

AI를 활용하여 어린이를 위한 맞춤형 동화책을 자동으로 생성하는 저작 도구입니다. 교육자와 부모가 손쉽게 교육용 콘텐츠를 제작하고, 어린이들이 학습 게임을 통해 즐겁게 배울 수 있는 통합 플랫폼을 제공합니다.

✨ 주요 기능
  • 동화책 자동 생성: AI가 스토리, 캐릭터, 삽화를 자동 생성
  • 캐릭터 레퍼런스: 일관된 캐릭터 이미지 생성 및 관리
  • 다국어 번역: 한국어 → 영어 자동 번역 지원
  • TTS 음성 생성: 페이지별 자동 음성 나레이션
  • 교육 콘텐츠: 어휘 학습 및 퀴즈 자동 생성
  • 학습 게임: 5가지 인터랙티브 게임 제공
  • 뷰어 모드: 공개 동화책 열람 및 읽기
  • 클라우드 저장: Cloudflare R2 기반 자동 백업

🔄 데이터 흐름
  1. 사용자 요청 → 프론트엔드 (author.html)
  2. API 호출 → Express 서버 (server.js)
  3. AI 처리 → Gemini API (이미지/텍스트 생성)
  4. 파일 저장 → R2 Storage (영구 저장)
  5. 메타데이터 저장 → R2 JSON (인덱싱)
  6. 응답 반환 → 프론트엔드 UI 업데이트

API 엔드포인트

🎨 동화책 생성 API

POST /api/generate-storybook

설명: AI가 동화책을 자동 생성 (스토리 + 캐릭터)

입력: { title, targetAge, artStyle, storyRequest, pageCount }

출력: { success, storybook: {...} }

POST /api/generate-character-image

설명: 캐릭터 레퍼런스 이미지 생성

입력: { name, description, artStyle, height }

출력: { success, imageUrl }

POST /api/generate-illustration

설명: 페이지 삽화 생성 (캐릭터 레퍼런스 활용)

입력: { sceneDescription, characterReferences, artStyle }

출력: { success, imageUrl }

POST /api/generate-cover

설명: 표지 이미지 생성

입력: { title, prompt, characterReferences, aspectRatio }

출력: { success, imageUrl }

📚 동화책 관리 API (CRUD)

GET /api/storybooks

설명: 모든 동화책 목록 조회 (인덱스 기반)

출력: { success, storybooks: [{id, title, coverImage, ...}] }

GET /api/storybooks/:id

설명: 특정 동화책 상세 조회

출력: { success, storybook: {...} }

POST /api/storybooks

설명: 동화책 생성/수정 (R2에 저장)

입력: 전체 동화책 JSON

출력: { success, message }

DELETE /api/storybooks/:id

설명: 동화책 삭제 (이미지 파일 포함)

출력: { success, message }

PUT /api/storybooks/:id/public

설명: 동화책 공개 상태 변경

입력: { isPublic: true/false }

출력: { success, isPublic, publishedAt }

👀 뷰어 API (공개 동화책)

GET /api/viewer/storybooks

설명: 공개된 동화책 목록 (viewer-metadata.json)

출력: { success, storybooks: [...] }

GET /api/viewer/storybooks/:id

설명: 공개 동화책 상세 (권한 체크)

출력: { success, storybook: {...} }

POST /api/viewer/refresh-metadata

설명: 뷰어 메타데이터 수동 갱신 (표지 동기화용)

출력: { success, message }

🎓 교육 콘텐츠 API

POST /api/generate-vocabulary-images

설명: 어휘 학습용 이미지 일괄 생성

입력: { words: [{word, meaning}], artStyle }

출력: { success, results: [{word, imageUrl}] }

POST /api/generate-quiz

설명: 이야기 이해 퀴즈 자동 생성

입력: { pages: [...] }

출력: { success, questions: [...] }

POST /api/generate-tts

설명: TTS 음성 생성 (Google TTS)

입력: { text, voiceConfig }

출력: { success, audioUrl }

🔧 유틸리티 API

POST /api/upload-image

설명: 이미지 파일 직접 업로드

입력: Multipart form-data (image file)

출력: { success, imageUrl }

DELETE /api/cleanup-image

설명: R2에서 이미지 삭제

입력: { imageUrl }

출력: { success }

GET /api/download-image

설명: 이미지 다운로드 프록시 (CORS 우회)

쿼리: ?url=...&filename=...

  • 컴포넌트화: 재사용 가능한 UI 컴포넌트 추출
  • 빌드 시스템: Webpack/Vite로 번들링 최적화

  • Lazy Loading: 이미지 및 섹션 지연 로딩

  • AI 음성 다양화: 캐릭터별 다른 목소리
